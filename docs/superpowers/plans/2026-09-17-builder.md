# Only for Human Builder Implementation Plan

**Goal:** Produce a bilingual Figma builder with GitHub-updatable screen definitions.
**Architecture:** Declarative JSON nodes are rendered locally; remote data is fetched at one commit and validated before replacing frames.
**Tech Stack:** Plain JavaScript, Figma plugin API, Node built-in tests.
**Spec:** docs/superpowers/specs/2026-09-17-builder-design.md

## Global constraints
English default, Korean available; desktop 1440px; no AI images; independent repository; fixed UTC deadline; no production website in this package.
